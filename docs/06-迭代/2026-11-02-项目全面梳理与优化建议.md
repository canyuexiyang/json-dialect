## 二、示例与场景覆盖

### 2.1 已有样本矩阵（54 组，110 个文件）

| 来源格式 | 样本数 | 代表场景 |
|---|---|---|
| `python` | ≈14 | 单/双引号、三引号、元组、尾随逗号、注释（行内/整行）、裸键、数字键、bool 键、NaN/带符号 NaN、大整数、浮点、顺序 |
| `json` | ≈14 | CJK、emoji、转义、换行、三引号、裸键、尾随对象、深层、重复键、数组 |
| `map` | ≈9 | 基础、嵌套、数组套数组/对象、CJK 嵌套、深层、空 Map、值内含 `=`、值内含空格 |
| `java` | **1** | `java_esc` |

**黄金输出**：`.out.py` 35 个 + `.out.json` 19 个 + **`.out.java` 0 个**。
**否定样本**（`neg_*`）：`neg_plain_arr` / `neg_plain_obj`。
**日志前缀**：8 个样本（时间戳、ISO、级别、线程名、方括号段、嵌套对象、数组、CJK 消息、Java/Py/Map 主体）—— 覆盖充分。

### 2.2 覆盖良好的场景

- 精度保全（实测：`12345678901234567890` / `1.0` / `1e5` / `0.1000` 全部原样输出）
- 尾部残留与多值报错（实测：`{"a":1} garbage` → 第 1 行第 8 列；`{"a":1}\n{"b":2}` → 多个并列值）
- 日志前缀识别（实测：三种典型前缀均正确切出）
- Map 空白保真（`{a=hello world}` → `"hello world"`）
- 路径定位（实测：`$.a` / `$.b[1]` / `$` 容器、Map 原文坐标命中正确）
- 嵌套深度上限 200（实测：200 层 OK，260 层报「嵌套过深」）

### 2.3 缺失场景（按重要性排序）

| # | 缺失场景 | 为什么重要 | 现状 |
|---|---|---|---|
| M1 | **Java 转义作为「输出目标」无黄金样本** | 目标矩阵 12 组合里 4 组（任一来源 → Java）从未被外部解释器校验 | `.out.java` 数量 = 0 |
| M2 | **转义 tab 完全无黄金样本 / 不进交叉校验** | 4 风格 × 2 方向 = 8 条链路只有单元测试，无「目标语言可反解」的外部证明 | `verify_with_python.py` 只处理 `samples/*.out.{py,json}` |
| M3 | **Java 作为「来源」只有 1 个样本** | 该格式是 4 大来源之一，且解析路径（先解码再解析）最特殊 | `java_esc` 1 组 |
| M4 | 控制字符 ` -` 与 `U+2028/U+2029` | 转义表有两条专门规则（`escape.ts:33,50,92`），无样本锁住 | 0 |
| M5 | BOM（U+FEFF） | lexer 有专门处理（`lexer.ts:143-149`），但样本与测试都未见 | 0 |
| M6 | 前导零数字（`012`、`-007`） | `normalizeNumber` / `stripLeadingZeros` 有分支，且严格档 Python 直接报错 | 0 |
| M7 | 混合写法 `{'a': true}`（Python 引号 + JSON 字面量） | **实测会被判成 JSON 并报错**（见 D10），是最常见的真实脏数据 | 0 |
| M8 | 超长单行（无换行）文档 | 与多行文档的错误行列、路径中段省略行为不同 | 0 |
| M9 | 空数组 / 空对象 / 纯注释输入的空态表现 | 实测 `# only comment` → 报「内容不完整」而非空态（见 D23） | 仅靠少量单测 |
| M10 | 转义 tab 的剥壳失败路径 | 实测 `"50% off"` (url/decode) 剥壳后报错，提示不提剥壳（见 D24） | 0 |

### 3.3 视觉一致性缺口（**最集中的一类问题**）

`styles.css` 1410 行里出现的 `.cm-*` 类名只有 6 个：
`.cm-editor` `.cm-line` `.cm-errorLine` `.cm-errorText` `.cm-errorGutter` `.cm-errorGutter-gutter`。

而 `editor.ts:125` 直接铺了 `basicSetup`，它带来这些**未被造型**的 CM6 部件：

| 部件 | 类名 | 后果 |
|---|---|---|
| 行号槽 | `.cm-gutters` / `.cm-lineNumbers` | CM6 默认灰底 + 默认字体，与「内嵌白 / 凹进读数窗」不搭 |
| 折叠箭头 | `.cm-foldGutter` | 同上；且是用户不知道的「意外功能」 |
| 活动行 | `.cm-activeLine` / `.cm-activeLineGutter` | CM6 默认高亮色，与本项目的 `--signal` 体系无关 |

| 选区与光标 | `.cm-selectionBackground` / `.cm-cursor` | 未定制 |

**这类问题 jsdom 测不出（无布局、无 CM6 渲染），只能真机量** —— 与坑 13 / 坑 16 同源。

### 3.4 主题适配

- **跟随系统**：只在 `init` 里读一次 `matchMedia`（`controller.ts:223`），**无 `change` 监听**。
- **运行时切换能力是死代码**：`editor.ts:104` 声明了 `themeCompartment`，但全项目**没有任何一处 `themeCompartment.reconfigure`**；`editor.ts:197 setEditable` 同样从未被调用。
- 因此「切系统深浅色」必须重载扩展才能生效（见 D4）。

## 四、交互逻辑

### 4.1 状态机

| 状态 | 触发 | UI 表现 | `ConvertStatus` |
|---|---|---|---|
| 空 | 输入为空 | 输出清空、按钮禁用、状态「粘贴内容即可自动转换」 | `empty` |
| 待处理 | 输入变化（防抖 200ms，>100k 时 300ms） | 状态「待处理」、输出置灰 + 「已过期」徽标、复制下载禁用 | — |
| 过大 | >500k 字符 | **关闭实时转换**，状态「文本过大，已关闭实时转换，请点「转换」」 | — |
| 成功 | 严格层一次过 | LED 绿、状态「已完成 · <输出语言>」 | `ok` |
| 已修正 | 宽松层过，有 marks | 修正提示条（>5 处加粗）+ 状态「已修正 · <输出语言>」 | `fixed` |
| 已回退 | 靠跨格式回退才成功 | 状态「已按 <格式> 格式解析」 | `fallback` |
| 报错 | 全部失败 | 状态红、错误行高亮 + 行号槽标记、输出保留上一次并置灰、复制下载禁用、给建议条 | `error` |
| 超时 | 3s deadline | 同上，状态「转换超时，建议用放大页面或拆分文本」 | `timeout` |

成功路径会清失败态（`controller.ts:962-970`）—— 补齐后角标移除、按钮解禁（AC-23）。

### 4.2 边界条件（实测）

| 边界 | 行为 | 评价 |
|---|---|---|
| 空 / 纯空白 | `status=empty`，输出空 | ✅ |
| 仅注释 `# x` | `status=error`「内容不完整」 | ⚠️ 更贴近空态（D23） |
| `{}` / `[]` | `status=ok`，输出 `{}` / `[]` | ✅ |
| 尾部残留 / 多值 | 精确行列报错 | ✅（历史缺陷已修） |
| 嵌套 >200 | 报「嵌套过深」，行列指向第 201 个 `[` | ✅ |
| 1M 字符 | `convert` 实测 169–215ms（node） | ⚠️ 阈值 T2=500k 偏保守（D19） |
| 超大整数/浮点 | 原样透传 | ✅ |
| 重复键 | 提示数量与键名，**全部保留不去重** | ✅ |
| 手动锁定后失败 | 不给「切来源」建议（已锁定） | ✅ |
| 日志前缀 | 只在报错时建议，**是否剥离由用户点击决定** | ✅ |
| 转义失败 | 不返回部分结果，保留旧输出置灰 + 禁用 | ✅ |

### 4.3 异常与空状态

| 环节 | 兜底 |
|---|---|
| `chrome.*` Promise 永不 settle | `withTimeout` 全覆盖（`sessionState.ts:62-85`），prefs 1.5s、session 1.5–2s |
| **初始化顺序** | 编辑器创建**必须先于任何 await**（历史 P0，坑 9）；`panel.ts` 刻意不含 await |
| storage 不可用 | prefs 走默认值继续，绝不阻塞交互 |
| 标签页交接失败 | 三种失败各有明确文案，「当前输入已保留」 |
| 侧边栏关不掉 | 官方 API → `window.close()` → 静默失败，不抛 |
| 复制失败 | 三级降级，末级自动全选引导 `Ctrl/Cmd+C` |
| 下拉装饰失败 | try 包住，静默降级回原生 `<select>` |
| CM6 布局未就绪 | `posAtCoords` / `fitPath` 均有 `clientWidth===0` 的跳过分支 |

### 6.2 上手成本

| 维度 | 评价 | 依据 |
