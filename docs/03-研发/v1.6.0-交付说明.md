## 三、行为变更（对外可见）

1. `Ctrl/Cmd+F` 由浏览器原生查找变回**编辑器内查找**，输入框与按钮沿用仪器面板视觉；`Tab` 仍可正常离开编辑器。
2. 值数 >50 时类型面板出现搜索框、上一页/下一页与页码，一次最多渲染 20 行；改覆盖时面板不再整块重绘、焦点不丢。
3. 严格档遇到 `# 注释`、`.5` 这类偏差会在修正条列出（输出内容不变），不再「悄悄改」。
4. 深色模式下编辑器底色、工具栏分隔线、小字颜色与设计令牌一致；过期输出可读性提高。
5. 切 tab 自动收起对比浮层；片段按钮标注来源通道，跨通道载入有提示。
6. 大文本点「对比」会给出明确拒绝/截断提示，不会瞬间生成数十万 DOM 节点。

## 四、回归与真机验收

- 新增 `tests/acceptance/v16-features.test.ts`（**9 项**）：严格档修正可见 ×2、类型面板降级/搜索翻页/指纹不重建 ×3、`releaseSelect` 断观察器、E4/N13/N14 源码契约 ×3。
- `v151-regressions.test.ts` 搭车 **3 项**：切 tab 关对比、跨 tab 片段来源、对比上限源码断言（合计 21 项）。
- `tools/v14-verify.mjs` 新增 **9 项真机断言**：三档宽度下 `Ctrl+F` 搜索面板存在 + 令牌化（原 K1 一条改两条 ×3 = +3）、深色 computed style 四条、64 值类型面板真降级 + 口径说明两条；原有 66 项全部复跑。
- 深色用 `emulateMediaFeatures(prefers-color-scheme: dark)` 新开页面量 `getComputedStyle`，不污染浅色断言；真机截图已归档入库：[深色 360px](v1.6-360-dark.png)、[64 值类型面板降级](v1.6-360-typepanel-degraded.png)。
- Python 交叉校验 83 项仍全绿：N10 只增加修正记录、不改变输出，`.out.*` 黄金样本无需重生成。
- **真机调试两处留档**：① N14 把 `.emptyhints` 改成 `top:0 + flex 居中` 后，示例按钮正好压在 `.cm-content` 中心，`fill()` 的坐标点击被按钮接走（真机报「未找到 token: userName」）→ 改为顶部对齐，且 `fill()` 直接用 `page.focus()` 不再坐标点击；② macOS 上 CM6 的 `Mod-f` 是 `Cmd+F`，被浏览器查找占用、网页收不到 keydown，用 `Ctrl+F` 也打不开面板 → 编辑器额外绑定 `Control-f`，README 与 FR-S7 明示 Mac 用户请用 `Ctrl+F`。
- 深色断言需读 `getComputedStyle(document.body)` 的自定义属性：深色令牌挂在 `body.theme-dark` 而非 `:root`，读 `:root` 会拿到浅色值造成假阴性。
