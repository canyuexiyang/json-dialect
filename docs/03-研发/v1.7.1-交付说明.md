## 三、行为变更（对外可见）

1. 放大页继承后继续编辑、切 tab、改类型覆盖，再刷新：恢复到最后一次编辑态，不再退回刚继承时的初始文本。
2. 从侧边栏放大进入「转义」tab：输入区不再出现 Python 语法高亮和折叠箭头。
3. 判定条左侧 LED 状态灯在自动识别 / 空态切换后仍然存在。
4. 解析失败时，输出区遗留的旧结果用其原本语言高亮，不再被本次检测语言错配。
5. 扩展描述由「双向转换」更正为四向转换（Python / JSON / Java 转义串 / Map.toString()）；不影响转换行为。

## 四、回归与真机验收

- 新增 3 项 `audit-ui-regressions.test.ts` 回归：继承 escape tab 无高亮/折叠、判定条 LED 保留、刷新快照导出当前 tab 与各工作区输入。
- 3 条假绿测试改为真断言：M3 用 >1M（T2）文本验证闸门；深浅色断言由控制器 `matchMedia` 加类而非测试自加；AC-32 剥注释后断言控制器实现。
- `verify:ui` 91 项全部复跑通过；真机控制台仅有静态服务器无 favicon 的 404 噪声，不影响断言。
- `shasum -a 256 -c SHA256SUMS.txt` 对现存 v1.6.0 / v1.7.0 / v1.7.1 产物全部 OK。
