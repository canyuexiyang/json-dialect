# v1.3.1 发布说明（2026-10-20）

本次为 v1.3.0 的缺陷修复版本，覆盖审查报告 D01–D17，保留侧边栏与独立标签页形态。

## 主要变化

- 解析正确性：非法数字明确报错；修复 Python 反斜杠、长 Unicode 转义；严格语法按来源区分；同格式整理保留 Python 元组与非字符串键语义。
- 类型调整：公共 IR 应用覆盖后再按目标输出；保留订单号前导零；特殊键与重复键路径互不影响；非法类型转换可直接纠正。
- 交互状态：错误态可切换容错；旧结果立即失效；三个功能 tab 独立保存输入、来源锁定和类型覆盖；日志前缀在编辑后重新确认。
- 会话交接：写入超时、标签页打开失败时保留原输入；多窗口使用独立会话标识；迁移包含其他工作区，读后清除。
- 性能与可达性：消除平铺对象的平方级路径收集；完整处理链路加入预算检查；高亮关闭真正卸载语言扩展；分隔条和下拉支持完整键盘流程。
- 发布门禁：对当前引擎运行样本，再由目标语言解释器与黄金样本比较类型、顺序和值，不再仅检查保存的旧输出。
