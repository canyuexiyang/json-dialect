## 三、开工顺序建议

```
立即可开工（无依赖、无待确认项）
  ├─ M0-1  lexer            ← 建议第一个做
  ├─ M1-0a Spike 剪贴板      ← 与 M0 并行，越早越好
  └─ M1-0b Spike CodeMirror  ← 与 M0 并行，越早越好

M0-1 完成后
  └─ M0-2 / M0-3 / M0-8 可并行

M0-4 完成后
  └─ M0-5 / M0-6 / M0-7 可并行

M0 全部完成 → M1 → M2 → M3（主线串行）
```

**三个「不要」**：
1. **不要跳过两项 spike** —— 它们验证的是"做不到就得换方案"的风险，拖到 M3 才发现等于白做
2. **不要把三层解析实现成多轮文本重写** —— 用「一次 token 化 + strict 开关」，否则会有修复顺序依赖与行列漂移
3. **不要让复制/下载读取编辑器 DOM** —— 必须取 IR 序列化结果（AC-39）

## 四、关键实现约束速查

| 约束 | 说明 |
|---|---|
| 纯函数 | `src/core/` 下禁止 import 任何浏览器 API 或 `chrome.*` |
| 数字精度 | 全程原始 token 透传，**永不调用 `Number()`** |
| token 化 | 一次扫描，四形态 parser 与打分器共享同一份 Token 流 |
| 引号算法 | 含 `'` 且不含 `"` → 用双引号 `"it's"` |
| 权限 | manifest 仅 `["storage"]`，无 `tabs` / `downloads` / `host_permissions` |
| 存储 | 界面偏好 → `storage.local`；跨页会话态 → `storage.session`；输入/输出**零落盘** |
| 输出来源 | 复制/下载内容取自 IR 序列化，**不取自 DOM** |
| 字符计数 | 按 Unicode 码点 `[...text].length` |
