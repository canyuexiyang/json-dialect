## 一、本次改了什么

事项「UI 界面重构」：在 v1.1.1 基础上重构插件页面所有元素（按钮、tab、下拉框等）。

**纯表现层重构，业务逻辑零改动。** 三个 tab 的转换行为、转义方向语义、
外层引号剥离、日志前缀处理等 v1.1.1 的全部业务行为均原样保留。

视觉方向定为**工业仪表面板**：2px 硬圆角、机加工细线、
输入「抬起台面」vs 输出「凹进读数窗」刻意不对等、按 tab 换色的通道导轨。
详见 `v1.2-UI设计规范.md`。
