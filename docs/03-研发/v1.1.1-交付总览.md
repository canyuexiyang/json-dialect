## 一、本次改了什么

结果测试反馈：**「转义 tab 下没有去除转义的选项」**。

排查结论：内核**有** decode 能力，但方向切换藏在底部按钮的隐式翻转里 ——
按钮只显示当前方向（「编码」/「解码」），用户点一下才知道它其实是切换器。
**这不是功能缺失，是可见性缺失，但用户体验上等价。**

> **格式化 tab 与转换 tab 零改动**（确认功能已满足需求）。

## 二、交互设计（转义 tab）

### 顶部：方向二选一，常驻可见

```
┌─────────────────────────────────────────────┐
│  格式化   转义   转换                        │  ← tab 条
├─────────────────────────────────────────────┤
│ [JSON 字符串 ▾]  [去除转义│增加转义]         │  ← 风格 + 方向
├─────────────────────────────────────────────┤
│  输入                                        │
│  ...                                         │
├─────────────────────────────────────────────┤
│  输出                                        │
│  ...                                         │
├─────────────────────────────────────────────┤
│ 已自动去除外层引号    [反向：去除转义][复制] │  ← 状态 + 操作
└─────────────────────────────────────────────┘
```

| 控件 | 行为 |
|---|---|
| **去除转义 / 增加转义** | 二选一，选中态实心高亮；点击立即重跑；选择持久化 |
| **底部按钮** | 转义 tab 下文案为「反向：xxx」—— 明确说出点完会变成哪个方向 |
| **状态条** | 剥了外层引号时显示「已自动去除外层引号」（可追溯） |

**默认值**：增加转义（与 v1.1.0 现状一致，不制造迁移成本）。
历史偏好覆盖默认值（FR-L3 同一优先级）。

### 使用方式

| 场景 | 操作 |
|---|---|
| 把 JSON 变成能贴进 Java 代码的字符串 | 方向 = 增加转义，风格 = Java 字符串 |
| 把日志里的 `{\"a\":1}` 还原成 JSON | 方向 = 去除转义（外层引号自动剥） |
| 中文转 Base64 / 反向 | 风格 = Base64，方向 = 增加 / 去除 |
| URL 参数编解码 | 风格 = URL 百分号 |

## 三、顺带修掉的真实痛点：外层引号

从 Java / JSON 代码里复制出来的常量**自带外层引号**：

| 输入 | v1.1.0（旧） | v1.1.1（新） |
|---|---|---|
| `"{\"a\":1}"` | `"{"a":1}"` ← 外层引号残留，要手删 | `{"a":1}` ✅ |

**安全判据**：不能只比较首尾字符。要扫描确认中间的同种引号**都被反斜杠转义**，
否则 `a" + "b` 会被误判（已加 AC-76 守住）。
四种风格都安全：url 编码后 `"` → `%22`，base64 字母表不含 `"`。

## 四、需求与验收

| ID | 内容 |
|---|---|
| **FR-I5** | 方向二选一常驻可见，不得藏进按钮翻转；默认增加转义；选择持久化 |
| **FR-I6** | 去除转义时剥离配对的外层引号，并显式提示「已自动去除外层引号」 |
| **FR-I7** | 任一风格下「增加转义 → 去除转义」往返还原原文 |
| **AC-74** | 打开转义 tab：二选一可见，默认增加转义，选中态清晰 |
| **AC-75** | `"{\"a\":1}"` + 去除转义 → `{"a":1}`，且提示已剥引号 |
| **AC-76** | `a" + "b` + 去除转义 → 原样输出，不得剥离 |
| **AC-77** | `"abc"` + **增加**转义 → `\"abc\"`，不得剥离 |
| **AC-78** | 四风格往返一致（含套外层引号的复制场景） |
| **AC-79** | 底部按钮翻转方向，文案同步 |
| **AC-80** | 记住上次选择（历史偏好覆盖默认值） |
