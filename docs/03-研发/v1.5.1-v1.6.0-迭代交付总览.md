## 四、关键决策与反转（解释两版为何这样切）

1. **N01 方案改轨**：直觉做法是把 1M 闸门下沉到 `run()`，但「仍要转换」和底部「转换」按钮也走 `run()`，会自锁。正解是统一 `guardOversize()`，显式入口直接放行。
2. **N11 / N06 由 P1 升 P0**：前者是历史 P0 事故（托管 Chrome 下 storage Promise 永不 settle → 界面点不动）在放大页入口的重演；后者是结果正确性缺陷，静默产出空串。
3. **E4 反转 v1.5 决策**：v1.5 用白名单扩展去掉 `searchKeymap`，让 `Ctrl+F` 回落浏览器原生查找；v1.6 因虚拟滚动命中率差恢复编辑器内查找，并把搜索面板/匹配高亮全部令牌化。`verify:ui` 中原 K1「Ctrl+F 不弹 `.cm-panels`」断言随之反转为「必须弹出且令牌化」。
4. **macOS 查找键**：CM6 `Mod-f` 是 `Cmd+F`，被浏览器查找占用、网页收不到 keydown；额外绑定 `Control-f`，README 与 FR-S7 明示 Mac 用 `Ctrl+F`。
5. **N10 不改输出**：严格档把偏差写进修正记录而非报错，Python 83 项黄金样本无需重生成 —— 「任何偏差都可见」不等于「任何偏差都失败」。
6. **N06 保留 `slot.raw`**：bool/null 才按节点语义 + `outLang` 生成文本；num/str 必须保留原始写法，否则 Map 前导零 `0012` 回归（`audit-regressions` 37 项曾红）。
7. **深色令牌单写**：删除 `@media` 与 `body.theme-dark` 双写，computed style 断言须读 `getComputedStyle(document.body)`（读 `:root` 会拿到浅色值造成假阴性）。
