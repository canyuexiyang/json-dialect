## 0. 规范地位与使用方式

### 0.1 唯一视觉语言

**🔴 强制**：本项目只有一套视觉语言，称为 **「中性精修」**：

- 白/近黑主面 + 两级中性灰层级；颜色只表达状态和可操作；
- 横向分隔线为主，几乎不画竖线；
- 主按钮反色（浅色黑底白字 / 深色白底黑字）；
- 蓝色只给焦点、选中、链接和代码关键字；
- 浮层用 0.5px 描边 + 轻阴影 + 12/16px 圆角。

不允许为单个页面另起一套配色、圆角、字体、图标或组件库。

| ⚪ **参考** | 示例、解释、历史说明 | 不作为验收项 |

## 1. 设计原则

**🔴 强制**：以下 10 条是评审前提，不是“尽量”。

1. **内容优先**：层级靠留白、字号、字重和分隔线组织，不靠大面积色块。
2. **一个视图一个主操作**：同一屏只有一个反色主按钮（本项目通常是「复制」）。
3. **状态必须可区分**：空态 / 成功 / 已修正 / 过期 / 报错 / 禁用，六种状态在视觉上必须分得开。
4. **蓝色克制**：蓝色只给焦点环、选中行、命中 token、链接和代码关键字；不要用蓝色铺背景。
5. **可键盘、可退出**：所有浮层有 Esc / 点外 / 关闭按钮三条退路；所有图标按钮有 `aria-label` / `title`。
6. **不做假交互**：按钮必须有响应；不可用必须说明原因；不出现点了没反应的控件。
7. **密度服从可读性**：侧边栏 320px 下可以收缩、换行、进菜单，但不能把关键控件裁掉。
8. **中文界面**：UI 文案只做简体中文；标识符、SQL、快捷键符号、代码保持原样。
9. **零网络**：字体、图标、样式全部本地；禁止 CDN、远程字体、埋点。
10. **不引入第二种风格**：新页面必须看起来像同一个产品，而不是另一个工具。

## 3. 设计令牌

### 3.1 唯一来源

**🔴 强制**：

1. 颜色、字体、间距、圆角、阴影、动效的数值只定义在 `src/ui/styles.css` 的 `:root` 与 `body.theme-dark`。
2. 组件样式只能通过 `var(--token)` 引用；不允许写 `#hex`、`rgb()`、`hsl()`、具名颜色。
3. `color-mix(in srgb, var(--token) N%, transparent)` 允许用于状态底色；混色源必须是令牌。
4. 新增 token 必须同时写入浅色 `:root` 与深色 `body.theme-dark`，并检查兼容别名是否需要重新声明（见 §3.5）。
5. 不允许 `var(--x, fallback)` 给新代码兜底；找不到 token 就是错。
6. 业务组件内联 `style` 只允许动态几何（宽度、位移、CSS 变量）；颜色和字体禁止内联。
7. 阴影/遮罩的 rgba 只能出现在令牌层；组件的 `box-shadow` 必须引用 `--dsw-shadow-*` / `--dsw-elevation-*`。

### 3.4 字体 / 尺度 / 阴影

**🔴 强制**：

```css
--dsw-font-family-text-default: -apple-system, BlinkMacSystemFont, 'SF Pro Text',
  'PingFang SC', 'Hiragino Sans GB', 'Archivo', 'Microsoft YaHei', 'Segoe UI', sans-serif;
--dsw-font-family-code-default: 'SF Mono', 'JetBrains Mono', 'Fira Code', 'Plex Mono',
  Menlo, Consolas, 'Liberation Mono', monospace;
```

| 组 | 值 | 说明 |
|---|---|---|
| 圆角 | 4 / 6 / 7 / 8 / 12 / 16 / 999 | tag 4；控件 6–8；面板 12；对话框 16；胶囊 999 |
| 间距 | 4 / 6 / 8 / 10 / 16 / 24 | 4px 网格；组件内 6–8，条带 10–16 |
| 发丝线 | `0.5px` | 高 DPR 下更接近原生描边 |
| 控件高 | 28px（标签页）/ 26px（侧边栏）/ 24px（xs） | 图标按钮 28×28 |
| 焦点环 | 2px `--signal` + 1px offset | 键盘可见 |
| 阴影 | `--dsw-shadow-lv1` / `--dsw-elevation-panel` / `--dsw-elevation-prominent` | 浮层用最后一级 |
| 图标 | 16 viewBox / 1.5 线宽 / `currentColor` | 品牌 mark 14；面板 tab 隐藏图标 |

### 3.5 深色的特殊规则（已踩过坑）

**🔴 强制**：深色只重绑语义层，**并且必须在 `body.theme-dark` 重新声明兼容别名**。

原因：`--bg: var(--dsw-alias-bg-base)` 在 `:root` 上已完成 `var()` 替换；`body.theme-dark`
只改 `--dsw-alias-bg-base` 不会让从 `:root` 继承下来的 `--bg` 重新求值。症状是深色下
`--bg` / `--text` / `--border` 仍是浅色值（白底黑字、深色代码区里出现黑字）。

```css
body.theme-dark {
  --dsw-alias-bg-base: #151517;
  /* …语义层… */
  --bg: var(--dsw-alias-bg-base);
  --bg-inset: var(--dsw-alias-bg-base);
  --bg-recess: var(--dsw-alias-bg-subtle);
  --text: var(--dsw-alias-label-primary);
  --border: var(--dsw-alias-border-l2);
  --signal: var(--dsw-alias-link);
  /* 兼容别名逐一重绑，见 styles.css */
}
```

**🔴 强制**：不得使用 `@media (prefers-color-scheme: dark)` 再写一份令牌；主题由控制器
同步段在创建编辑器前给 `body` 加 `theme-dark`，并监听 `matchMedia.change` 运行时切换。

## 4. 布局

### 4.1 两种承载形态

| 形态 | 宽度 | 结构 | 差异 |
|---|---|---|---|
| 侧边栏 `panel` | 320–400px | 顶栏 / 判定条 / 路径条 / 输入 / 分隔条 / 输出 / 底栏 | 两行底栏；模式 chip + 更多菜单；品牌副标隐藏；tab 图标隐藏 |
| 标签页 `tab` | 整屏（≥ 720px 才有意义） | 同上 | 单行底栏；模式按钮直接可见；无放大按钮 |

**🔴 强制**：两种形态共用 `src/ui/shell.ts` 的同一份模板，差异只由 `app--panel` / `app--large`
与占位块（放大按钮、更多菜单）承担；不得复制两份 DOM。

### 4.2 条带高度

| 条带 | 侧边栏 | 标签页 |
|---|---|---|
| 顶栏 | 40 | 46 |
| 判定条 | 40（转义两行约 67） | 46 |
| 路径条 | 30 | 32 |
| 输入/输出头 | 30 | 34 |
| 分隔条 | 6 | 7 |
| 底栏 | 73–75（两行） | 56 |
| 代码 | 11.5 / 1.66 | 12 / 1.66 |

**🔴 强制**：320px 下不得出现页面级横向滚动；不得裁掉 `#btnConvert`、`#btnCopy`、
`#btnDownload`、`#enlarge`、`#statusMsg` 与底栏。320/360 两档为必测宽度。

### 4.3 侧边栏底栏

**🔴 强制**：

- 底栏固定两行：第一行状态 + 模式 chip，第二行 `转换 / 复制 / 下载 / 更多`。
- 复制是唯一反色主按钮；下载在侧边栏收成图标按钮（`title` / `aria-label` 保留完整文案）。
- 「档位 / 缩进 / 存为片段 / 对比」移入更多菜单；**当前档位必须在状态行 chip 始终可见**。
- 更多菜单从整个底栏上方弹出，不压住状态行；右对齐，距右 10px，距底栏 8px。
- 更多菜单只能**移动**既有按钮，不得复制按钮（ID、事件监听、`hidden` 语义保持）。

## 5. 组件

### 5.1 顶栏与品牌

- 品牌块：22px（侧边栏 20px）反色圆角块 + `brand__mark` 13/12px 600 + `brand__sub` 9px
  等宽（侧边栏隐藏）。品牌块图标为 `{ }` 线性图标，`currentColor`。
- 功能 tab：30px（侧边栏 28px），圆角 8，gap 2；选中态 = 内容面底色 + 0.5px 边 + `shadow-lv1`，
  不使用底部色条或整块品牌色。
- 右侧：`本地处理` 胶囊（侧边栏隐藏）+ 放大按钮（仅侧边栏，图标 + 标签；标签在侧边栏隐藏）。
- **🔴 强制**：tab 选中态只能有一个；tab 文本不得换行；图标仅作辅助，不替代文字。

### 5.2 判定条

- 结构：识别状态点（6px）→ 来源下拉 → 锁定/回退徽章 → `输出 · …` 提示（格式化）→ 箭头 →
  目标下拉（转换）→ 转义风格/方向/包裹开关（转义）→ 弹性空隙 → `自动识别`（宽屏）。
- 下拉触发器 28/26px：`来源/目标/风格` 小标签 + 当前值 + caret；选项菜单 4px 内边距、行高 30。
- 识别点：待输入灰、自动识别绿、手动锁定琥珀；`fmtLabel` 的文字在视觉上隐藏，但保留给读屏/测试。
- **🔴 强制**：不得新增第二套下拉；原生 `<select>` 必须保留在 DOM 中（视觉隐藏）以承载
  表单语义、测试与无障碍；装饰失败要静默回退原生控件。
- **🔴 强制**：转义 tab 隐藏来源/目标/路径条；格式化 tab 隐藏目标下拉；`输出 · …` 在
  格式化 tab 显示，Map 回退时显示 `输出 · Python 字面量`。

### 5.3 路径条

- 32/30px；`路径` 9.5px 等宽 → 路径 11.5/11px 等宽 → 类型徽章 → 提示 → `复制`。
- 选中路径后隐藏提示；路径过长时中段省略（控制器已有），不得撑破布局。
- 空/错误态用无衬线占位文案（`pathbar__path--empty`），不用假路径。
- **🔴 强制**：路径条只在格式化/转换出现；转义 tab 隐藏；错误态明确说「无法定位」并禁用复制。

### 5.4 输入 / 输出区与编辑器

- 输入区白 `--bg-base`；输出区 `--bg-subtle`，只读；两者靠头部的 `EDIT` / `READ ONLY`
  和底色区分，不使用凹陷/内阴影。
- 头部 34/30px：标题 12/11.5 → kicker 9.5 等宽 → 统计 → 清空/过期徽章。
- 代码：`SF Mono` 栈，12/11.5px，行高 1.66，行号槽 30–34px，折叠槽 14px。
- CM 主题：行号槽 `--bg-recess` + `--border` 右边；活动行 `--active-line`；选区 `--sel-bg`；
  光标 `--signal`；折叠占位符 `--bg-recess` + `--border-strong`；查找面板全令牌化。
- 语法高亮用 `HighlightStyle.define` + CSS 变量，**不得再使用 `oneDark`**（它会接管底色与
  深色语法色）。批量括号/配对括号必须令牌化，否则深色下会出现黑底黑字。

## 6. 交互与状态

### 6.1 六态

| 状态 | 视觉 | 行为 |
|---|---|---|
| 空 | 灰点 + 「粘贴内容即可自动转换」+ 空态卡片 | 示例可点；复制/下载禁用 |
| 成功 | 绿点 + 「已完成 · …」 | 主按钮可用 |
| 已修正 | 琥珀修正条 + 「已修正 N 处」 | 可展开明细 |
| 过期 | 输出压暗去色 + 琥珀「已过期」 | 复制/下载禁用 |
| 报错 | 红点 + 错误文案 + 错误行 | 保留上一份输出；建议条出口 |
| 待机/大文本 | 灰点/警告条 | 说明原因，给一键转换 |

### 6.2 焦点与键盘

- **🔴 强制**：所有可交互控件有 `:focus-visible` 2px 蓝色焦点环，offset 1px。
- Tab 顺序：顶栏 → 判定条 → 路径条 → 输入区 → 分隔条 → 输出区 → 状态/模式 chip → 动作。
- `Esc` 顺序：对比浮层 → 自绘下拉 → 更多菜单 → （侧边栏）二次确认关闭。更多菜单的 Esc
  在 capture 阶段消费，不让控制器继续走「关闭侧边栏」。
- 编辑器内 `Esc` 保留 CM6 语义（简化选区）；`Tab` 不被编辑器拦截。
- 所有图标按钮必须有 `aria-label`；菜单触发器维护 `aria-expanded`。

### 6.3 反馈与动效

- 复制成功：按钮文字变「已复制」2s，保留图标；禁止 `textContent` 清空图标。
- 悬停：中性灰底；按下：更深一档；禁用：opacity .42 + `cursor: default`。
- 入场：顶栏/判定条/双区/底栏 300ms 错峰淡入；`prefers-reduced-motion` 下全部关闭。
- 大文本降级（`.is-lite`）关闭装饰动效。

## 7. 响应式

**🔴 强制**：

1. 320 / 360 / 500 三档为必测宽度；页面级 `scrollWidth ≤ clientWidth`。
2. 320px 下：
   - 品牌副标、`本地处理`、tab 图标、`自动识别` 隐藏；
   - 底栏动作行 `转换 / 复制 / 下载（图标）/ 更多` 不换行；
   - 错误状态文字最多 190px，超出省略，不得挤掉模式 chip；
   - 更多菜单最小 216px、右对齐、完整落在卡片内。
3. 转义 tab 判定条允许两行：风格 + 方向一行，包裹引号一行；不得横向溢出。
4. 标签页在窄独立窗口下底栏允许换行；不得隐藏核心按钮。
5. 侧边栏不使用横向滚动救场；能收进菜单的收进菜单。

### 8.1 文件职责

| `src/ui/panel.ts` / `app.ts` | 入口、同步段/异步段 | await 先于编辑器创建 |

### 8.2 命名与兼容

- **🔴 强制**：旧 class / id 是测试与真机脚本的契约，不得为了“干净”重命名；
  新样式在旧选择器上叠加新类。
- 新组件用 BEM 近似命名：`.品牌__元素`、`.组件--修饰`；状态类 `.is-*` / `.--on` 按既有习惯。
- 新按钮/输入必须有稳定 `id`（若被控制器/测试引用）与 `aria-label`。
- 新增 DOM 节点必须通过 `qOpt` 读取，保证老测试挂载的精简 DOM 仍能运行。
- 新增 `DomRefs` 字段一律 optional；控制器里必须 `if` 保护。

### 8.3 图标

- 内联 SVG，16 viewBox，`fill:none`、`stroke:currentColor`、线宽 1.5；不引入图标库。
- 品牌 mark 14；按钮图标 14；菜单/统计 16；状态点用 CSS 圆点，不用图标。
- 禁止 emoji、外部图标字体、CDN。

### 8.4 字体与零网络

- 系统字体优先；`Archivo` / `Plex Mono` 是本地 woff2 兜底，约 55KB。
- **🔴 强制**：禁止 CDN `@font-face`、远程字体、远程图标；`check:privacy` 必须继续通过。
- 中文走 PingFang / 苹方 / 微软雅黑；不要给中文强行套等宽字体。

## 11. 变更流程

1. 先确认改动属于 **令牌 / 组件 / 布局 / 交互** 哪一层；
2. 改 `styles.css` 令牌或组件；禁止在页面里写样式；
3. 若是新组件，补 `DomRefs` optional 字段与老 DOM 兜底；
4. 跑 §10 门禁；
5. 更新本规范对应章节 + PRD（若涉及需求/验收）+ 交付说明；
6. 截图归档到 `docs/03-研发/v1.8-*.png`；
7. 评审通过后再提交；提交信息写清视觉批次与版本。

### 11.1 评审清单

- [ ] 没有新增未定义 token / 硬编码颜色
- [ ] 深色是独立取值，不是反相；兼容别名已重绑
- [ ] 主按钮唯一；蓝色只用于焦点/选中/链接/代码关键字
- [ ] 320/360 无横向滚动，底栏不被裁，菜单不越界
- [ ] 焦点可见；Esc/点外/关闭三退路
- [ ] 图标按钮有 `aria-label`；文案不换行/不截断关键信息
- [ ] 复制/下载不读 DOM；下载文案与扩展名一致
- [ ] `verify:all` + `verify:ui` 全绿
- [ ] 文档/截图/版本号同步
