### 快捷键冲突

- **K1**：`Ctrl/Cmd+F` 不再被 CM6 拦截（白名单移除 searchKeymap），回落浏览器原生查找 —— 真机断言锁住。
- **K2**：CM6 的 `Ctrl+A` 只全选当前编辑器（设计使然），新增 `Mod+Shift+A` 直达「全选输出并聚焦」。
- **K3**：Esc 分层语义固化：对比浮层 → 自绘菜单 → 侧边栏关闭；焦点在编辑器内时不抢 CM6「简化选区」。

### 缺失场景（M1～M10）

样本矩阵 54 → **67 组**（+13），全部进交叉校验：Java 来源 ×3（嵌套/CJK/顶层数组）、Java 目标 ×4、混合写法（D9）、控制字符与 U+2028、BOM、前导零、空容器组合、超长单行（3381 字符）；转义黄金样本 16 条（含 wrapQuotes 与剥壳往返）。
M9（仅注释空态）与 M10（剥壳失败提示）由 AC-115/AC-116 用例锁住。

### 贯穿性建议（第二门禁）

`tools/v14-verify.mjs` 升级为 **改 UI 必跑**的第二门禁（`npm run verify:ui`），固化三类 jsdom 测不出的断言：
① CM6 部件令牌是否落地（computed style）；② resize 后路径省略是否仍无溢出；③ 浮层是否被滚动容器裁切。
另加 K1（Ctrl+F 无 CM6 面板）与 D12（空态示例）真机断言。

## 三、行为变更（对外可见）

1. 转义 tab 风格下拉从 4 项变 3 项（JSON 与 Java 合并）；新增「包裹外层引号」开关（默认关，偏好持久化）。
2. 转换 tab 出现「压缩/美化」按钮；「转换」按钮文案变「重新转换」。
3. 关闭实时转换的阈值从 500k 提到 1M；超限提示条带「仍要转换」按钮。
4. 路径条在转换 tab 也出现；占位文案改为「点选输入或输出中的键或值」。
5. 空输入判定条显示「待输入」而非「标准 JSON」；空态出现一键示例。
6. 严格档报错多一个「改用容错档重试」按钮。
7. `Ctrl+F` 不再弹出 CM6 搜索面板（回落浏览器原生查找）。
8. 下载文件名含毫秒。
