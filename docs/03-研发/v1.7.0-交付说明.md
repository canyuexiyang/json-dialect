## 三、行为变更（对外可见）

1. json / python 输入与输出区出现折叠槽箭头；点击折叠为 `[+]` 文本占位符，点击占位符恢复。
2. `Alt+Click` 箭头为手风琴（折全部同级）；快捷键见 README 快捷键表（`Ctrl/Cmd+Shift+[` 等）。
3. 转义 tab 输入区无折叠点（纯文本通道）。
4. **已知限制**（v1.6.0 起存在的既有缺陷，本版排查后如实记录）：切 tab 后首次 `Ctrl/Cmd+F` 可能打不开搜索面板——编辑器内敲任意一键即恢复；PRD FR-T 段与 README 均有记录，留候选池待升级 @codemirror/* 后复测。

## 四、已知限制的排查结论（switchTab 后 Ctrl+F）

40+ 轮 puppeteer 探针二分定位（2026-11-13）：
- 坏条件 = `switchTab` 恢复输入（编程式 setDoc 全量替换）+ 该 tab 首次 Ctrl+F；keymap 命中（prevented=true）但 `.cm-panels` 不出现；输入/输出区同坏。
- exceptionSink 无捕获、console/pageerror 零输出；`view.setState()` 全量重建（含全新 extensions）**不能修复**——判定为 CM6 上游 panelPlugin 在编程式全量文档替换后的边角行为。
- 三版修复尝试（setState(Transaction) / setState(tr.state)+显式 onChange / setState(create+buildExtensions)）真机全部无效且引入 jsdom 回归，**全部回退**；setDoc 保持原 dispatch 实现。
- 缓解：verify:ui 断言顺序固化（E4 先于任何 tab 往返，FR-T 块后置自包含）；真实用户场景影响极小（切 tab 后本就要重新聚焦编辑器）。

## 五、回归与真机验收

- 新增 `tests/acceptance/v17-features.test.ts`（**15 项**）：语言分流 ×4、`[+]` 占位符与折叠恢复 ×3、统计不变、setDoc 重置、storage 零写入源码断言、foldKeymap ×2、CSS 令牌源码断言、只读输出区可折、错误行高亮共存。
- `tools/v14-verify.mjs` 新增 **16 项真机断言**：三档宽度折叠槽箭头存在 / 真实坐标点击折叠出 `[+]` / 占位符恢复 / 折叠槽令牌化 / 转义 tab 零箭头（×3 宽度）+ 深色折叠槽令牌 1 项；原有 75 项全部复跑。
- 真机调试留档（写进 MEMORY）：① 单行 JSON 无折叠点是 CM6 正确语义（区间须跨行），折叠断言必须灌多行文档；② 折叠箭头断言用 `.cm-foldGutter .cm-gutterElement span` 且要求非零宽高（spacer 是 hidden 的 `▸`）；③ 合成 MouseEvent 对 CM6 gutter 无效（无坐标 posAtDOM 算不出行），必须真实坐标点击。
