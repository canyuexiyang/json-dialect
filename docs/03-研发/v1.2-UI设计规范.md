# JSON Dialect v1.2 —— UI 设计规范

> 对应事项：UI 界面重构（在 v1.1.1 基础上重构插件页面所有元素：按钮、tab、下拉框等）
> 产出日期：2026-09-23
> 版本：**v1.2.0**（已打包 `json-dialect-dist-v1.2.0.zip`）

---

## 1. Purpose Statement

JSON Dialect 是一个纯本地 Chrome MV3 扩展，在 Python 字面量 / 标准 JSON / Java 转义字符串 /
`Map.toString()` 四者之间做转换。使用者是开发者：从日志或调试输出里复制一段乱成一团的数据，
需要立刻看清、立刻能用。

界面运行在 **720×600 的弹窗**里，也可放大到整页。纵向空间极其紧张，每一个横向条带都要精打细算。
且本扩展承诺 **零网络请求**，任何视觉方案都不得引入外部资源。

## 2. Aesthetic Direction

**工业仪表面板（Industrial / utilitarian instrument panel）**

把整个插件当作一台精密测量仪器来画，而不是又一个消费级卡片界面。核心手法：

- 机加工细线（hairline rule）分隔，而非卡片投影堆叠
- **2px 硬圆角**，拒绝消费级软糖圆角
- 凹进的「读数窗」与抬起的「工作台面」刻意不对等
- 技术角标、等宽数码读数（`tabular-nums`）
- 按 tab 切换的「通道信号色」，让通道状态不用读文字也能看见
- 铭牌式字标（nameplate）

刻意避开「modern / clean / simple」这类无指向性的形容——这不是简约风，是仪器风。

## 4. Typography

- **Archivo**（可变字重 500–700）— UI 文本。机械感 grotesque，非 Inter / Roboto / Arial
- **IBM Plex Mono**（400/500）— 代码、路径、数码读数

**零网络约束下的处理**：两款字体的 woff2（共约 55 KB）已下载至 `src/ui/fonts/`，
由 Vite 打包进 `dist/assets/`。**不使用任何 CDN `@font-face`** —— 那会直接违反 AC-36/37。

中文无对应字形，退回 PingFang SC / Microsoft YaHei。这是唯一保留的系统字体依赖，
仅为中文覆盖，UI 拉丁文本一律走 Archivo。

## 5. Layout Strategy

**左重右轻，绝不居中。**

- 应用左缘 3px「通道导轨」，颜色随 tab 变
- 顶部条：铭牌居左 → tab 靠左续排 → 放大按钮钉死右侧
- 判定条沿一条渐宽细线展开「来源 ▸ 目标」，方向性一眼可见
- 输入区 = 抬起的**工作台面**（高亮底）；输出区 = 凹进的**读数窗**（低亮底 + 内阴影）
  —— 刻意不对等，不是两张一模一样的卡片
- 底栏：状态（含 LED 灯）居左，动作钉右，主 action 与其余按钮间距分组且略高

## 6. 组件规范

| 组件 | 规范 |
|---|---|
| tab | 高 40px（放大页 46px），选中态 = 底部 2px 信号色实心条 + 字重 700，不用整块填充 |
| 按钮 | 26px 高（主 action 28px），1px 描边，`active` 时下压 1px + 去投影（机械按键感） |
| 下拉框 | 原生 select 无法造型 → 改为「触发器按键 + 自绘浮层菜单」，详见 §7 |
| 方向二选一 | 连体双向拨杆，选中段信号色实心 |
| 分隔条 | 6px，中间三点抓握纹，hover 变信号色 |
| 修正提示条 | 左缘 3px 警示灯带，点击展开明细 |
| 状态灯 | 三态：灰（待机）/ 绿（就绪）/ 红（故障） |

## 7. 下拉框重构的关键约束

原生 `<select>` 的下拉面板由浏览器绘制，无法统一造型 —— 在仪器面板方向下它会是唯一一处
「不像这台机器」的控件。改为自绘菜单时，**以下契约必须保留**（改 UI 不能改行为）：

1. 真实 `<select>` **保留在 DOM 中**（视觉隐藏），承载既有测试与无障碍语义
2. 自绘菜单的选择写回原生 select 并派发原生 `change` —— 控制器只监听 change，完全无感
3. `.hidden` 语义不变：控制器靠它按 tab 显隐
4. `value` / `options` 读取仍有效（测试直接读 `sel.options`）

装饰失败一律**静默降级**回原生 select —— 视觉一致性让位于界面可用性。

## 8. 动效

- 入场：整台仪器「通电」，各条带 0.05s 错峰淡入，播完即摘 class
- tab 指示条：切换时 `scaleX` 弹性吸附
- 菜单：6px 位移 + 淡入
- 复制成功：整键闪一次信号色（原来只改文字，反馈太弱）
- `prefers-reduced-motion` 下全部关闭
- 大文本（> 100k 字符，FR-G3 降级档）挂 `is-lite` 关掉装饰性动效

## 9. 已修的两个「测试测不出」的缺陷

浏览器默认 `[hidden]{display:none}` 会被组件自身的显式 `display` 覆盖，
导致判定条上留下空白缺口：

1. `.seg`（方向拨杆）、`.badge` 设了 `display:inline-flex` → 全局补 `[hidden]{display:none !important}`
2. `.sel` 容器同理，但控制器只隐藏内部原生 select → 在 `bindHiddenClose` 里让容器跟随同步

二者都只在真机量高度时才暴露，197 个测试全绿也发现不了。
