## 8.1 核心规则专项（P0，必须 100% 通过）

| # | Given | When | Then |
|---|---|---|---|
| AC-01 | 输入 `{'name': '张三', 'age': 18, 'vip': True}` | 粘贴后自动转换 | 输出标准 JSON，`"vip": true`，中文不转义，2 空格缩进 |
| AC-02 | 输入含 `False` 与 `None` 的 Python 字面量 | 转换 | 输出 `false` 与 `null`，位置与数量完全对应 |

| AC-04 | 输入大整数 `{'id': 12345678901234567890}` | 转换 | 输出 `12345678901234567890`，**不得**变为 `12345678901234567000` 或科学计数法 |

### 8.4 容错与报错（P1）

| # | Given | When | Then |
|---|---|---|---|
| AC-17 | 输入 `{'a': 1, }`（末尾逗号） | 粘贴 | 自动修复，输出 `{"a": 1}`，显示「已自动修正 1 处」，**不报错** |
| AC-18 | 承接 AC-17 | 展开修正提示 | 列出「第 1 行：删除末尾多余逗号」 |
| AC-19 | 输入带 `#` 注释的 Python 片段 | 粘贴 | 注释被剥离，输出合法 JSON，修正条列出剥离位置 |
| AC-20 | 输入 `{name: 'x'}`（键名无引号） | 粘贴 | 自动补引号，输出 `{"name": "x"}` |
| AC-21 | 输入 `{'a': 1`（缺右括号） | 粘贴 | 第 1 层与第 2 层均无法安全修复 → 报错「第 1 行第 N 列：缺少右括号」，高亮该行 |
| AC-22 | 承接 AC-21 | 查看输出区 | 上一次成功结果保留但置灰并标「已过期」，复制与下载按钮禁用 |
| AC-23 | 承接 AC-21 | 用户手动补齐 `}` | 转为「已修复」或「已解析」状态，按钮解禁，角标移除 |
| AC-24 | 输入完全无法识别的乱码 | 粘贴 | 给出行列级定位与原因分类，并提示可手动切换来源格式（FR-D10） |

> **AC-21 的边界说明**：缺右括号时，若缺失位置在文本末尾且结构唯一可确定，第 2 层**可以**自动补齐；只有当无法确定补齐位置（如多处括号嵌套、歧义）时才进入第 3 层报错。测试用例应构造**歧义场景**来验证报错路径，而非简单缺一个末尾括号。
