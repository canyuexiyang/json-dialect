## 验证与产物

- `npm run verify:all`：287 个测试通过，类型检查、54 个当前输出的独立目标语言解析和黄金样本语义比对、生产构建、隐私静态检查通过。
- 新增 55 个专项回归用例；旧测试中与修复冲突的分隔条方向/比例，以及“打开失败仍关闭侧边栏”的断言已纠正。
- Python 门禁现在直接运行当前引擎，不会覆盖样本期望；同时比较类型、顺序和值，防止陈旧输出和 `True == 1` 掩盖问题。
- 实际浏览器验证使用生产构建、Playwright、320px 窄屏、控制台与网络事件观测；证据与限制见前端报告。
- 复测平铺 3 万字段的同类样本由审查时约 4.17 秒降至百毫秒量级；精确数值依赖机器和并发负载。
- `dist/` 已重新构建；尚未提交 Git、发布 Release 或升级 package/manifest 版本。

## 保留边界

Map.toString 文本本身可能丢失类型和边界信息，不承诺任意文本无损恢复。当前解析器仍面向文档约定的字面量子集，不执行 Python/Java 代码。同步 deadline 是检查点中止，不能使主线程解析变成后台任务。

真实 Chrome 扩展的 worker 生命周期、跨浏览器标签页存活、MV3 CSP、权限下的剪贴板及真实跨窗口侧边栏关闭未重新验收。新增功能候选另行确定范围。
